About This Course

Python Programming is designed to help students understand the fundamentals of Python and develop practical programming skills.

The course covers variables, data types, operators, conditional statements, loops, functions, lists, tuples, dictionaries, file handling and object-oriented programming.

Learning Objectives

  • Understand Python programming fundamentals
  • Work with variables and data types
  • Use conditional statements and loops
  • Create and use Python functions
  • Work with lists, tuples and dictionaries
  • Understand object-oriented programming
